# Security Policy

## Supported versions

This repository does not currently contain a released application. Once releases begin, document which versions receive security updates in this section.

## Reporting a vulnerability

If you discover a security vulnerability, please avoid opening a public issue with exploit details. Instead, contact the repository maintainers through the project's preferred private reporting channel.

When reporting a vulnerability, include as much detail as possible:

- A description of the issue and its potential impact.
- Steps to reproduce the behavior.
- Affected files, configurations, or deployment settings.
- Any suggested mitigations or patches, if available.

Maintainers should acknowledge reports, investigate impact, and coordinate disclosure before publishing fixes or advisories.
